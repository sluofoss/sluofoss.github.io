# graph analytics libraries
### static python
- networkx
- rustworkx
- [igraph](https://python.igraph.org/en/stable/tutorials/configuration.html#sphx-glr-tutorials-configuration-py)

### interactive python and/or other
- [pyvis](https://pyvis.readthedocs.io/en/latest/)
  - works together with networkx
- [infovis](https://philogb.github.io/jit/demos.html)
  - javascript front end
  - https://stackoverflow.com/questions/6020615/interactive-graphviz-graphs-in-a-web-application
- [d3.js](https://d3js.org/)
  - javascript library for producing dynamic, interactive data visualizations in web browsers
- plotly dash + cytoscape.js
  - https://js.cytoscape.org/
- gephi
